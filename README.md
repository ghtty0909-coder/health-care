# 렙체크 AI

반복 품질 분석 기반 부상 예방형 웨이트 트레이닝 AI 자세 분석 앱 (컴퓨터공학특강 DD831 · 트랙 B · Physical AI)

세트 영상을 올리면 MediaPipe Pose Landmarker가 기기 안에서 관절 33개를 추출하고, 반복마다 횟수·깊이·템포·자세 붕괴·좌우 불균형을 분석합니다. 서버·회원가입 없이 오프라인으로 동작합니다.

## 빠른 시작
```
npm install          # MediaPipe 라이브러리·모델을 www/ 로 복사
npm test             # 합성 관절 데이터로 분석 엔진 검증
npm run serve        # 브라우저에서 http://localhost:8080
npx cap sync android # 웹 코드를 안드로이드 프로젝트로 복사
npx cap open android # Android Studio에서 열기
```
자세한 빌드·서명·원스토어 등록 방법은 [docs/GUIDE.md](docs/GUIDE.md)를 보세요.

## 구조
| 경로 | 내용 |
|---|---|
| `www/js/analysis.js` | 관절 각도 계산, 반복 구간 분리, 운동별 지표, 첫 3회 기준 자세 붕괴, 좌우 불균형, 템포 |
| `www/js/pose.js` | MediaPipe 초기화(GPU→CPU 대체), 영상 프레임 처리(재생 속도 자동 조절) |
| `www/js/app.js` | 화면, 리포트, 관절 오버레이 다시보기, 기록·무게별 그래프 |
| `www/js/storage.js` | 기기 내 저장(localStorage) |
| `www/privacy.html`, `docs/privacy.html` | 개인정보처리방침 (docs/ 는 GitHub Pages용) |
| `store/` | 원스토어 등록 문구, 아이콘, 그래픽 이미지, 스크린샷 |
| `android/` | Capacitor 안드로이드 프로젝트 |
